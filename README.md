# Disease Symptoms & Exploratory Data Analysis (EDA)

A data processing and exploratory analysis project focused on understanding symptom features, clinical parameters, and disease distribution across health outcomes.

## 📌 Project Overview
This repository contains an exploratory data analysis workflow built using Python and Pandas. The primary objective is to inspect, clean, and analyze a dataset containing clinical symptoms and patient outcomes.

### Dataset Profile
- **Total Records:** 349 entries
- **Total Features:** 10 columns
- **Unique Conditions:** 116 unique health conditions
- **Target Variable:** Outcome Variable

## 📊 Dataset Features
The dataset consists of demographic, clinical, and categorical symptom indicators:
- `Disease`: Target medical condition
- `Fever`, `Cough`, `Fatigue`, `Difficulty Breathing`: Categorical indicators (`Yes`/`No`)
- `Age`: Numerical patient age
- `Gender`: Male / Female
- `Blood Pressure`: Blood pressure level categorical variable
- `Cholesterol Level`: Cholesterol level categorical variable
- `Outcome Variable`: Final diagnosed clinical outcome
